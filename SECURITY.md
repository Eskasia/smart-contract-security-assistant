# Security Policy

## Supported Scope

This project accepts security reports for vulnerabilities in the Smart Contract
Security Assistant codebase, documentation, CI, packaging, and local analysis
workflow.

Do not use this project or its issue tracker to publish private keys, secrets,
customer contracts, proprietary audit reports, or code that you are not
authorized to review.

## Authorized Use

Only scan, upload, test, or review Solidity projects that you own, maintain, or
are explicitly authorized to assess. Reports involving third-party systems must
include confirmation that you have permission to test them.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by emailing the maintainer:

```text
58102604+Eskasia@users.noreply.github.com
```

Include:

- A concise description of the issue.
- Reproduction steps or a minimal proof of concept.
- The affected command, module, or workflow.
- Impact and any known mitigations.
- Whether the report contains sensitive or third-party material.

## Response Expectations

The maintainer will aim to acknowledge valid reports within 7 days and provide
an update within 30 days. Timelines may vary based on report complexity and
maintainer availability.

## Public Disclosure

Please do not publicly disclose a vulnerability until a fix, mitigation, or
coordinated disclosure plan is available.
