Status: published release record.

## Scope

- API fail-closed default for `/api/*` token auth, non-local host binding,
  request Origin, JSON write body, CORS wildcard, and input path policy.
- README mapped detector boundary and formal finding promotion scope.
- Public report schema synchronized from the internal `REPORT_SCHEMA`.
- Public `AGENTS.md` cleanup with no local absolute paths.
- CI verification for report schema sync.

## Remaining Limitations

- SCSA is triage, not full audit certification.
- Only mapped detector output is promoted to formal findings.
- External adoption evidence is still in progress.
- Package publication is distribution evidence, not adoption evidence.
- Downloads should remain uncounted until a package-hosted download counter or
  another explicit public download source exists.
