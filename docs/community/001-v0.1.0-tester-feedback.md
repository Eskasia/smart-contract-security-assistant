# v0.1.0 Tester Feedback Guide

Status: active
Updated: 2026-05-31
Release: https://github.com/Eskasia/smart-contract-security-assistant/releases/tag/v0.1.0

## Goal

Collect reproducible feedback from Solidity/Web3 users who can run the v0.1.0
quickstart and report whether the local-first audit workflow works on their
machine.

## Who Should Test

- Solidity developers.
- Web3 hackathon builders.
- Smart contract auditors or audit learners.
- OSS maintainers reviewing Solidity pull requests.

## Safety Boundary

Only test contracts that you own, maintain, or are explicitly authorized to
review. Do not upload private keys, secrets, proprietary contracts, customer
audit material, or unpublished third-party reports.

The project is for first-pass triage and reproducible human review. It is not a
replacement for a full audit.

## Quickstart Test

Run from a clean clone:

```bash
git clone https://github.com/Eskasia/smart-contract-security-assistant.git
cd smart-contract-security-assistant
uv sync --extra audit --dev
uv run scsa analyze tests/contracts/VulnerableVault.sol --out-dir reports-demo
uv run pytest
```

Expected output summary:

```text
overall_status: finding
finding: f_001 | reentrancy | severity 3 | withdraw | SWC-107
human_review_required: true
pytest: 15 passed
```

Generated local files:

```text
reports-demo/10679f2de6b7.json
reports-demo/10679f2de6b7.md
reports-demo/analysis_trace.sqlite
```

## Optional Authorized Contract Test

If you own or are authorized to review a Solidity contract, run:

```bash
uv run scsa analyze path/to/YourContract.sol --out-dir reports-local
```

Share only a summary in GitHub issues unless the contract is public and safe to
include.

## Maintainer Collection Target

Before the Codex for Open Source application, collect at least 3 independent
tester reports or equivalent public usage signals:

- GitHub issue comments from testers.
- External repo mention using the released tag.
- Public article/post referencing the quickstart.
- Release download, clone, star, or fork evidence.
